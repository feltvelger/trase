# Traséverifisering

Tegneverktøy for feltverifisering av fibertraseer (Tom Hvaal AS). Åpne siden på iPad i Safari og velg **Del → Legg til på Hjem-skjerm**.

Prosjektliste, traseer og avregningsmal hentes fra Google Disk med koblingsnøkkelen. Tegninger, kommentarer og bilder lagres på enheten og kopieres automatisk til Google Disk.
